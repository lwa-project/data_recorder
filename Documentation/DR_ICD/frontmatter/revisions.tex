2.4.1 & 2026-02-06 & All &
    Major revision matching DROS version 2.4.1.0:
    \begin{itemize}[nosep,leftmargin=*]
        \item Reformatted to \texttt{lwa-icd.cls} template.
        \item Replaced DP references with NDP throughout.
        \item Removed TBN, TBW, and TBF data formats.
        \item Added DRX8, TBT, TBS, and COR data format support.
        \item Updated spectrometer documentation: multiple Stokes products
              (XXYY, CRCI, IQUV, IV, XXCRCIYY, I), flexible FFT length and
              integration count, Stokes metadata parameter.
        \item Added multi-DR deployment documentation
              (\texttt{build\_helper.py}, per-instance configuration).
        \item Updated storage documentation: single drives preferred,
              RAID-0 arrays still supported for legacy DRSU compatibility.
        \item Updated configuration parameters for \texttt{defaults\_v2.cfg}.
        \item Updated system requirements for modern Linux.
        \item Added systemd service deployment documentation.
        \item Added SHT, PNG, and RPT commands to command summary.
        \item Added Appendix~C (data format reference).
    \end{itemize} \\
